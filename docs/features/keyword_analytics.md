# Keyword Performance & Analytics Specification

## Overview
The **Keyword Insights & Analytics** module (`/keywords`) aggregates keyword tokens across all portfolio assets and platform sales records in SQLite, providing deep conversion visibility, tier categorization, earnings ranking, and direct portfolio drill-down.

## Core Features & Mechanics

### 1. Keyword Token Aggregation & Metrics
- **Extraction**: Tokenizes comma-separated keywords across all `Image` records with case-insensitive normalization.
- **Metrics Computation**:
  - `frequency`: Total number of active portfolio assets tagged with this keyword.
  - `totalDownloads`: Accumulated downloads across all linked assets.
  - `totalEarnings`: Accumulated revenue ($) generated by linked assets across all microstock platforms.
  - `rpi` *(Revenue Per Image)*: `totalEarnings / frequency` ($/asset) — indicates asset efficiency.
  - `rpd` *(Revenue Per Download)*: `totalEarnings / totalDownloads` ($/download) — indicates license value tier.
  - `isTopFive` & `topFiveCount`: Tracks how many times the keyword appears within the first 5 words of an artwork (highest microstock SEO weight).
  - `score`: Weighted composite score for default ranking.

### 2. Keyword Performance Tiers
Each keyword is classified into one of 5 discrete efficiency tiers:
- 💎 **Draw More (High ROI Niche)**: High return per image (`frequency <= 3 && totalDownloads >= 3 && rpi >= 15`). Signals high market demand with low portfolio supply — prime candidate for expanding into a 10–20 vector artwork series.
- 🌟 **Star**: High conversion or high earnings (`rpi >= 1.5` or `rpd >= 1.0` or `totalEarnings >= 20` or `totalDownloads >= 25`).
- 📦 **Workhorse**: Steady, reliable performer with standard conversion rates.
- 💤 **Dormant**: Used in `>= 3` artworks but has 0 total downloads and 0 revenue (stale / non-performing tags).
- ⚪ **Untested**: Present in `< 3` artworks with 0 sales yet.

### 3. Interactive Data Table & Filtering
- **Time Range Velocity**: Quick-toggle filter pills for `All Time`, `30 Days`, `90 Days`, and `1 Year` to isolate current sales velocity and trending terms.
- **Sorting**: Multi-column sorting by Earnings, Downloads, Assets (Frequency), RPI ($/image), RPD ($/download), or Alphabetical.
- **Search**: Real-time filtering by keyword substring.
- **Tier Filters**: Quick-filter tabs for `all`, `draw_more`, `star`, `workhorse`, `dormant`, and `untested`.
- **Multi-Selection & Batch Copy**: Checkbox selection with floating action bar to copy selected tags directly to clipboard in standard comma-separated format.

### 4. Artwork Drill-Down Slide-over & Recipe Generator
- Clicking any keyword row opens `KeywordDetailDrawer` which queries `/api/portfolio?searchField=exactKeyword&search={keyword}`.
- **🏆 Winning Tag Combinations (Recipe)**: Computes top co-occurring keywords across linked artworks ranked by joint revenue and co-occurrence frequency, with a 1-click `[ Copy Tag Recipe ]` action button.
- Displays thumbnail previews, codes, titles, upload dates, downloads, and earnings for all matching artworks.
- Allows 1-click inspection of any individual artwork in `PortfolioDetail`.

### 5. Guidelines Modal
- Dedicated `KeywordGuideModal` explaining Performance Tiers, Column Metrics (with heavy emphasis on TOP 5 SEO priority weighting), Time Range Velocity, and Winning Tag Combination strategies.
